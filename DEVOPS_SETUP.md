# X-Stream DevOps Pipeline Setup

This guide explains how to set up the CI/CD pipeline, infrastructure, and monitoring for the X-Stream project on AWS.

## Architecture Overview

- **AWS EC2**: Hosts the Jenkins CI/CD server, Kubernetes cluster (Minikube), Docker, and Monitoring tools.
- **Terraform**: Provisions the required AWS EC2 instance and Security Groups.
- **Jenkins**: Automates the build, push, and deployment of Docker images to Kubernetes.
- **Kubernetes**: Orchestrates the Frontend and Backend containers.
- **Prometheus & Grafana**: Monitors the Kubernetes cluster and application performance.
- **Docker**: Containerizes the Frontend and Backend node applications.

## Prerequisites
- AWS Account and CLI configured
- Terraform installed
- Docker Hub Account
- Jenkins accessible via `<EC2_PUBLIC_IP>:8080`

## 1. Infrastructure Provisioning (Terraform)
Navigate to the `terraform` directory in the backend repository:
```bash
cd terraform
terraform init
terraform apply -auto-approve
```
This will output the `public_ip` of the EC2 instance. SSH into this instance to continue.

## 2. CI/CD Setup (Jenkins)
1. Access Jenkins at `http://<EC2_PUBLIC_IP>:8080`.
2. Retrieve the initial admin password from `/var/lib/jenkins/secrets/initialAdminPassword` on the EC2 server.
3. Install suggested plugins and set up your admin user.
4. Add Credentials in Jenkins:
    - **Docker Hub**: ID: `dockerhub-credentials` (Username & Password)
    - **Kubernetes Config**: ID: `k8s-kubeconfig` (Secret file containing `~/.kube/config` generated by Minikube on the EC2 instance)
5. Create a new Pipeline Job, point it to the GitHub repository, and select `Jenkinsfile`.

## 3. Kubernetes Deployment
The Jenkins pipeline automatically builds the Docker image, pushes it to Docker Hub, and applies the `k8s/deployment.yaml` and `k8s/service.yaml` files.
You can manually apply them on the EC2 server via:
```bash
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml
```

## 4. Monitoring (Prometheus & Grafana)
Navigate to the `monitoring` directory and start the stack:
```bash
cd monitoring
docker-compose up -d
```
1. **Prometheus**: Accessible at `http://<EC2_PUBLIC_IP>:9090`
2. **Grafana**: Accessible at `http://<EC2_PUBLIC_IP>:3000` (Default login: `admin`/`admin`)
Add Prometheus as a Data Source in Grafana using the URL `http://prometheus:9090`.

## GitHub Branches
All DevOps configurations are kept in the separate `aws` branch of both the Frontend and Backend repositories to ensure application source code is unaffected until merged.
